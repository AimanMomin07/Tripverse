# TripVerse

Features:
- Firebase Authentication (Email/Password + Google)
- Animated Login page (luxury theme)
- Onboarding modal (?is_new_user=true)
- Flights page with seat selection & group-split
- My Trips saved in localStorage

Setup:
1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env` and fill in the Firebase project values.
3. Start the development server with `npm run dev`.
4. Open the local URL printed by Vite.
